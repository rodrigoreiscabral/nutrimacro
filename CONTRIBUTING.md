# Guia de Contribuicao

1. Crie uma branch para sua funcionalidade ou correcao (`git checkout -b feature/minha-feature`).
2. Garanta que todos os testes passem com 100% de cobertura (`npm run test:coverage`).
3. Execute a suite de testes ponta a ponta (`npm run test:e2e`).
4. Faca commits seguindo a convencao de Conventional Commits.
5. Abra um Pull Request detalhando as alteracoes realizadas.
