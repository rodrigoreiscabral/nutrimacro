# Changelog

Todas as mudancas notaveis neste projeto serao documentadas neste arquivo.

## [1.0.0] - 2026-10-30
### Adicionado
* Modulo de calculo para Taxa Metabolica Basal (Mifflin-St Jeor e Harris-Benedict).
* Calculo de Gasto Energetico Total Diario com cinco fatores de atividade.
* Distribuicao automatica de macronutrientes por objetivo corporal.
* Suite de 30 testes unitarios com 100% de cobertura no Vitest.
* Suite de 5 testes ponta a ponta com Playwright.
* Esteira automatizada de CI com GitHub Actions.
